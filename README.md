# 航碳智脑：民航碳效智能决策平台

> Aviation Carbon Intelligence Platform — 服务"十五五"碳达峰攻坚期

---

## 项目简介

航碳智脑是面向国内航空公司的碳排放核算与减排方案生成平台。基于航线、机型、燃油结构、客座率和碳价格等数据，完成航班级碳排放核算，并生成低成本、可落地的组合减碳方案。

**适用场景**：本科生"零碳"比赛路演展示。

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动网站

```bash
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。

### 3. 修改机场数据

编辑 `airports.csv` 文件，按照以下格式添加或修改机场：

```
机场名称,城市,ICAO代码,IATA代码,纬度,经度,机场等级
```

- 纬度/经度为十进制格式
- 机场等级：`枢纽` 或 `普通`

### 4. 修改默认价格

在 `app.py` 中找到 `DEFAULTS` 字典（约第 200 行），修改以下值：

```python
DEFAULTS = {
    "航空煤油价格": 6500,      # 元/吨
    "SAF价格": 16000,          # 元/吨
    "碳价": 80,                # 元/吨CO2
    "SAF生命周期减排率": 0.70,  # 70%
    "LTO附加系数": 1.15,
    "CO2排放因子": 3.15,       # 吨CO2/吨燃油
}
```

## 核算逻辑说明

核算遵循 **ISO 14064** 的温室气体量化、边界设定、活动数据采集、排放因子计算和可追溯披露原则。航空排放量采用"活动数据 × 排放因子"方法估算。

核心公式链：

```
航距(Haversine) → 巡航时间 → 巡航油耗 → LTO附加 → 年度燃油消耗 → CO₂排放
```

## 注意事项

- 所有默认价格均为演示估算值，可由用户修改
- SAF 价格趋势预测为情景分析，不代表市场承诺
- 正式应用需接入航司实际运行数据
- 适用于 Python 3.9 及以上版本
